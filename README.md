# Auto Bookmarks 2.0.1

Auto Bookmarks scans the active editor and displays grouped matches in its own **Activity Bar** container on the left side of VS Code.

- Click a match to reveal its line.
- Use the gear in the Bookmarks view title or `Auto Bookmarks: Open Settings` from the Command Palette.
- Select text in the editor, right-click, and use `Auto Bookmarks: Add Selected Text`.
- All configuration is deliberately written to VS Code **User/Global** settings, never Workspace settings.
